# Product Strategy Memo (2026-05-07)

## Context

User requested candid marketing/product feedback on future directions for the AI Context Builder project.

## Key Conclusions

1. Specialized "vertical" context apps likely have strong demand.
2. A hiring/team-fit product direction is viable and differentiating.
3. Best strategy is platform + vertical fronts, not one generic app only.

## 1) Specialized Context Apps (Different Direction)

### Bottom line

- Demand likely exists.
- Potentially easier to scale than a fully generic builder.

### Why

- Generic builders have high cognitive load ("what should I input?").
- Vertical products reduce onboarding friction with domain templates.
- Vertical language and outputs improve perceived relevance quickly.

### Candidate verticals

- Founder / executive decision protocol app
- Creator (video/writing) tone + taboo protocol app
- Manager 1on1 response protocol app
- Support/sales team response consistency app
- Personal self-dialog / reflection protocol app

## 2) Expansion to Hiring / Compatibility

### Bottom line

- Feasible and potentially strong.
- Could be differentiated if framed as "actionable protocol match", not just a score.

### Potential products

- Candidate vs company protocol fit view
- Team composition / role fit view
- Partner compatibility (founder/freelancer) fit view

### Risks to manage

- Explainability and fairness in hiring contexts
- Avoid "fortune telling" UX framing
- Keep evidence linked to explicit protocol statements

## Recommended Strategic Model

- Keep current app as core protocol engine (platform).
- Launch specialized front-ends for narrow ICPs.
- Add "protocol comparison" layer for hiring/team-fit products.

## Practical Near-Term Plan

1. Pick one vertical ICP and ship a focused pilot.
2. Reuse current core (protocol structure + quality checks + export/test).
3. Measure activation and retention vs generic flow.
4. If traction is good, add second vertical and comparison mode.

## Positioning Hypothesis

"Human Protocol OS" with:

- Builder core (current)
- Vertical copilots (specialized apps)
- Comparison products (fit/matching)
